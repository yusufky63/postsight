# postsight.xyz

The public website for the Postsight extension: a landing page, the privacy policy and a support page, in English (`/`) and Turkish (`/tr`). It is a static build with no runtime server, hosted on Vercel.

| URL | Built from |
|---|---|
| `/`, `/tr` | `site/src/content.ts`; action names, tier names and model defaults come from `src/shared/locales/*.ts` and `src/shared/models.ts`, screenshots from `store/screenshots/` |
| `/privacy`, `/tr/privacy` | `PRIVACY.md`, rendered at build time with the extension's own Markdown parser. The Turkish page wraps the English policy with a short Turkish note. |
| `/support`, `/tr/support` | GitHub links in `site/src/config.ts`; the FAQ is `help.q1`..`help.q8` and `help.a1`..`help.a8` from the locale files |

Edit `PRIVACY.md`, the locales or the screenshots and the next build picks the change up. The build fails if `PRIVACY.md` loses its `# ` title.

## Commands

Run from the repository root.

| Command | What it does |
|---|---|
| `pnpm site:dev` | Builds into `site/dist`, rebuilds on change and serves it at http://localhost:4320 with Vercel's URL rules from `vercel.json` (`/privacy` serves `privacy.html`, `/tr/` redirects to `/tr`, `404.html` for anything missing) and its headers |
| `pnpm site:build` | Writes the static site to `site/dist` and refreshes `vercel.json` when the theme script's CSP hash changes |
| `pnpm site:og` | Re-renders the share cards `site/og/og-en.png` and `site/og/og-tr.png` (1200 x 630) with a local Chrome or Edge, or the browser in `CHROME_PATH`. Run it after changing the card in `site/src/og.ts` and commit the PNGs; the build only copies them. |

`pnpm check` typechecks the site, runs its tests (`site/src/site.test.ts`) and builds it along with the extension.

## What the build writes

- One HTML file per page and language, plus one `404.html` that says it in English and Turkish, since Vercel serves the same 404 page for every missing path. Every page has its title, description, canonical URL on https://postsight.xyz, `hreflang` alternates, Open Graph and Twitter tags with the 1200 x 630 card, and JSON-LD (`SoftwareApplication` on the home page, `FAQPage` on support).
- `assets/`: CSS, the theme toggle script, screenshots and share cards, named by content hash and cached for a year.
- `fonts/`: DM Sans, Space Grotesk and JetBrains Mono, the same files the extension bundles.
- `favicon.ico` and `icons/` from `public/icons`, `site.webmanifest`, `robots.txt`, `sitemap.xml`, `llms.txt`.
`vercel.json` at the repository root is generated by the build from `site/src/seo.ts`; commit it when the build says it changed (a test fails if the committed copy is stale). It sets:

- the build: `pnpm install --frozen-lockfile`, `pnpm site:build`, output in `site/dist`;
- `cleanUrls` and no trailing slash, so every page has one URL (`/privacy.html` and `/tr/` redirect);
- a Content-Security-Policy that allows only same-origin files plus the inline theme script by hash, and the other security headers;
- a year of caching for `assets/` and `fonts/`, whose file names carry a content hash;
- `noindex` on the `vercel.app` hostnames, which duplicate postsight.xyz;
- an ignored build step: a commit that changes none of the site's inputs (`site/`, `PRIVACY.md`, `src/shared`, `src/ui`, `store/screenshots`, `public`, `package.json`, the lockfile, `vercel.json`) does not redeploy.

## Vercel

The Vercel project `postsight` (scope `yusufky63s-projects`) is connected to `yusufky63/postsight`: every push to `main` deploys to production, and every other branch gets a preview. The build settings come from `vercel.json`; the project's Node.js version is 24.x, the version CI uses. The site needs no secrets or environment variables.

Custom domain: add `postsight.xyz` under the project's Settings, Domains, then `www.postsight.xyz` redirecting to the apex. From the CLI, in the repository root after `vercel link`:

```bash
vercel domains add postsight.xyz
```

## Layout

| File | Role |
|---|---|
| `site/build.mjs` | Bundles `src/generate.ts` for Node with esbuild and runs it |
| `site/serve.mjs` | Local server with Vercel's routing and headers |
| `site/og.mjs`, `site/browser.mjs` | Share card rendering over the DevTools protocol; one headless browser, removed with its temporary profile afterwards |
| `site/src/content.ts` | English and Turkish copy |
| `site/src/pages.ts`, `layout.ts` | Page bodies, the shared head, header and footer |
| `site/src/seo.ts` | Sitemap, robots, llms.txt, `vercel.json`, manifest, JSON-LD |
| `site/src/site.css` | Layout; tokens and font faces come from `src/ui/tokens.css` and `src/ui/fonts.css` |
| `site/src/client.ts` | The light/dark toggle, the only script; without it the site follows the system theme |
