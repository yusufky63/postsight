# Fiche de la boutique (français)

## Name
Sift : vérification des faits et recherche par IA pour X

## Short description
Vérifiez, approfondissez, résumez, traduisez et copiez les posts sur X avec votre propre clé API Claude, OpenAI ou DeepSeek.

## Description
Sift ajoute un petit bouton IA à chaque post sur X. En un clic, vous obtenez :

- Vérifier : un verdict (exact, trompeur, faux, opinion, etc.), un indice de confiance, une analyse affirmation par affirmation et les sources qui l'étayent, grâce à la recherche web en direct.
- Approfondir : le contexte, les faits clés datés, les personnes impliquées et les points de désaccord.
- Résumer : un TL;DR en une ligne et l'essentiel, y compris pour les fils, les posts cités, les X Articles et les articles de presse liés.
- Traduire : dans votre langue, en conservant les liens et les mentions.
- Expliquer : le jargon, les références, les mèmes et l'ironie, rendus clairs.
- Idées de réponse : trois brouillons sur des tons différents, à copier. Sift ne publie jamais à votre place.
- Demander : n'importe quelle question sur le post.
- Copier : le texte, le lien ou une citation prête à l'emploi.

Utilisez votre propre clé. Sift fonctionne avec Claude, OpenAI et DeepSeek. En mode auto, il choisit un modèle léger et économique pour les tâches simples et un modèle plus puissant avec recherche web pour les vérifications. Vous pouvez aussi choisir le modèle post par post.

Maîtrisez vos dépenses. Chaque résultat affiche les tokens, les recherches web, le coût et la durée. Définissez des budgets mensuels par fournisseur et voyez ce qu'il vous reste, et à peu près combien de tokens cela représente.

Lit ce vers quoi pointent les posts. Sift lit les X Articles et, avec votre autorisation, les pages d'actualité et de blog vers lesquelles renvoie un post : un post qui ne contient qu'un lien n'est donc pas jugé sur son seul titre.

Confidentialité dès la conception. Les clés restent dans votre navigateur et ne sont envoyées qu'au fournisseur choisi. Il n'y a ni serveur Sift ni suivi.

Disponible dans ces langues : English, Türkçe, Deutsch, Español, Français, Português, Italiano, Русский, 日本語, 한국어, 简体中文 et Bahasa Indonesia.
