# 商店介绍（简体中文）

## Name
Postsight：适用于 X 的 AI 事实核查与研究

## Short description
使用你自己的 Claude、OpenAI 或 DeepSeek API 密钥，对 X 上的帖子进行事实核查、研究、总结、翻译和复制。

## Description
Postsight 会在 X 的每条帖子上添加一个小巧的 AI 按钮。点击一下即可：

- 核查：给出结论（准确、有误导性、不实、观点等）、置信度、逐条说法的说明及其依据来源，并使用实时联网搜索。
- 研究：背景信息、带日期的关键事实、相关人物以及各方的分歧所在。
- 总结：一句话 TL;DR 加上核心内容，涵盖帖子串、引用帖、X Article 和链接的新闻页面。
- 翻译：译成你的语言，链接和提及保持不变。
- 解释：讲清术语、典故、梗和反讽。
- 回复建议：三条不同语气的草稿供你复制。Postsight 从不替你发帖。
- 提问：就帖子提出任何问题。
- 复制：文本、链接或现成的引用。

使用你自己的密钥。Postsight 支持 Claude、OpenAI 和 DeepSeek。在自动模式下，简单任务会选用轻量、便宜的模型，事实核查则选用更强、可联网搜索的模型；你也可以为每条帖子自选模型。

花费一目了然。每个结果都会显示 token 用量、联网搜索次数、费用和耗时。你可以为每个服务商设置每月预算，查看剩余金额以及大约还能用多少 token。

读懂帖子指向的内容。Postsight 会读取 X Article，并在你允许的情况下读取帖子所链接的新闻和博客页面，因此只含链接的帖子不会仅凭标题被评判。

钱包卡片（可选）。将鼠标悬停在帖子中的钱包地址或 .eth 名称上，即可了解其背后是谁：名称、关联资料、信誉和安全警告；如果是代币，还会显示市场数据、模拟交易和创建者。卡片还会说明该钱包是否属于发帖人。只使用公开来源，无需密钥，在你悬停之前不会发送任何内容。

隐私优先。密钥保存在你的浏览器中，只会发送给你选择的服务商。没有 Postsight 服务器，也没有任何追踪。

支持 12 种语言。
