# ストア掲載情報（日本語）

## Name
Postsight: X向けのAIファクトチェックと調査

## Short description
お手持ちのClaude、OpenAI、DeepSeekのAPIキーで、Xのポストをファクトチェック、調査、要約、翻訳、コピーできます。

## Description
PostsightはXのすべてのポストに小さなAIボタンを追加します。ワンクリックで次のことができます。

- 検証: 判定（正確、ミスリード、誤り、意見など）、確信度、主張ごとのメモとその根拠となる出典を、リアルタイムのWeb検索をもとに示します。
- 調査: 背景、日付付きの重要な事実、関係者、意見が分かれている点をまとめます。
- 要約: 1行のTL;DRと要点。スレッド、引用ポスト、Xの記事、リンク先のニュースページにも対応します。
- 翻訳: 設定した言語に翻訳します。リンクやメンションはそのまま残ります。
- 解説: 専門用語、元ネタ、ミーム、皮肉をわかりやすく説明します。
- 返信案: トーンの異なる下書きを3件用意し、コピーして使えます。Postsightが代わりに投稿することはありません。
- 質問: ポストについて自由に質問できます。
- コピー: テキスト、リンク、そのまま使える引用。

自分のキーで使えます。PostsightはClaude、OpenAI、DeepSeekに対応しています。自動モードでは、簡単な作業には軽量で安価なモデルを、ファクトチェックにはWeb検索ができる高性能なモデルを選びます。ポストごとに自分でモデルを選ぶこともできます。

使った金額がわかります。すべての結果にトークン数、Web検索の回数、コスト、所要時間が表示されます。プロバイダーごとに月間予算を設定すると、残りの金額と、それで使えるおおよそのトークン数を確認できます。

ポストのリンク先まで読みます。PostsightはXの記事を読み、許可すればポストがリンクしているニュースやブログのページも読み込みます。リンクだけのポストを見出しだけで判断することはありません。

プライバシーを重視した設計です。キーはブラウザ内に保存され、選んだプロバイダーにのみ送信されます。Postsightのサーバーはなく、トラッキングもありません。

English、Türkçe、Deutsch、Español、Français、Português、Italiano、Русский、日本語、한국어、简体中文、Bahasa Indonesiaに対応しています。
