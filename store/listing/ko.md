# 스토어 등록 정보(한국어)

## Name
Postsight: X용 AI 팩트체크와 조사

## Short description
내 Claude, OpenAI, DeepSeek API 키로 X 게시물을 팩트체크, 조사, 요약, 번역하고 복사하세요.

## Description
Postsight는 X의 모든 게시물에 작은 AI 버튼을 추가해요. 클릭 한 번으로 다음을 할 수 있어요.

- 검증: 판정(사실, 오해의 소지, 사실 아님, 의견 등), 신뢰도 점수, 주장별 메모와 그 근거가 된 출처를 실시간 웹 검색으로 보여 줘요.
- 조사: 배경, 날짜가 담긴 주요 사실, 관련 인물, 의견이 갈리는 지점을 정리해요.
- 요약: 한 줄 TL;DR과 핵심 내용. 스레드, 인용 게시물, X 아티클, 링크된 뉴스 페이지까지 포함해요.
- 번역: 설정한 언어로 번역하고, 링크와 멘션은 그대로 유지해요.
- 설명: 전문 용어, 레퍼런스, 밈, 아이러니를 쉽게 풀어 줘요.
- 답글 아이디어: 톤이 다른 초안 3개를 복사해 쓸 수 있어요. Postsight가 대신 게시하는 일은 없어요.
- 질문: 게시물에 대해 무엇이든 물어볼 수 있어요.
- 복사: 텍스트, 링크, 바로 쓸 수 있는 인용문.

내 키로 사용해요. Postsight는 Claude, OpenAI, DeepSeek와 함께 작동해요. 자동 모드에서는 간단한 작업에는 가볍고 저렴한 모델을, 팩트체크에는 웹 검색이 가능한 강력한 모델을 골라요. 게시물마다 직접 모델을 고를 수도 있어요.

얼마나 쓰는지 알 수 있어요. 모든 결과에 토큰, 웹 검색, 비용, 소요 시간이 표시돼요. 제공업체별로 월 예산을 설정하면 남은 금액과 그 금액으로 쓸 수 있는 대략적인 토큰 수를 확인할 수 있어요.

게시물이 가리키는 글까지 읽어요. Postsight는 X 아티클을 읽고, 허용하면 게시물에 링크된 뉴스와 블로그 페이지도 읽어요. 링크만 있는 게시물을 제목만 보고 판단하지 않아요.

설계부터 프라이버시 중심이에요. 키는 브라우저에만 보관되고 선택한 제공업체로만 전송돼요. Postsight 서버도, 추적도 없어요.
