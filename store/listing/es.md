# Ficha de la tienda (español)

## Name
Sift: verificación de datos e investigación con IA para X

## Short description
Verifica, investiga, resume, traduce y copia posts de X con tu propia clave de API de Claude, OpenAI o DeepSeek.

## Description
Sift añade un pequeño botón de IA a cada post de X. Con un clic obtienes:

- Verificar: un veredicto (correcto, engañoso, falso, opinión y más), una puntuación de confianza, notas afirmación por afirmación y las fuentes que las respaldan, con búsqueda web en tiempo real.
- Investigar: contexto, datos clave con fecha, quién está implicado y en qué discrepa la gente.
- Resumir: un TL;DR de una línea y lo esencial, incluidos hilos, posts citados, Artículos de X y páginas de noticias enlazadas.
- Traducir: a tu idioma, sin romper enlaces ni menciones.
- Explicar: jerga, referencias, memes e ironía, bien aclarados.
- Ideas de respuesta: tres borradores en tonos distintos para copiar. Sift nunca publica por ti.
- Preguntar: cualquier pregunta sobre el post.
- Copiar: el texto, el enlace o una cita lista para usar.

Usa tu propia clave. Sift funciona con Claude, OpenAI y DeepSeek. En modo automático elige un modelo ligero y barato para las tareas sencillas y uno más potente, con búsqueda web, para las verificaciones; o eliges tú el modelo en cada post.

Controla lo que gastas. Cada resultado muestra tokens, búsquedas web, coste y tiempo. Fija presupuestos mensuales por proveedor y consulta cuánto queda y a cuántos tokens equivale, más o menos.

Lee lo que enlazan los posts. Sift lee los Artículos de X y, con tu permiso, las páginas de noticias y blogs que enlaza un post, para que un post que solo contiene un enlace no se juzgue por el titular.

Privacidad desde el diseño. Las claves se quedan en tu navegador y solo van al proveedor que elegiste. No hay servidor de Sift ni seguimiento.

Disponible en English, Türkçe, Deutsch, Español, Français, Português, Italiano, Русский, 日本語, 한국어, 简体中文 y Bahasa Indonesia.
